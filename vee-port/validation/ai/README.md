# MicroAI Test Suite

This folder contains a ready-to-use project for testing [MicroAI](https://docs.microej.com/en/latest/VEEPortingGuide/microai.html) implementations on a device.
This Test Suite will test to open and run inferences on models.

## Specifications

- Tested Foundation Library: [MicroAI](https://repository.microej.com/modules/ej/api/microai/)
- Test Suite Module: [com.microej.pack.microai#microai-testsuite](https://repository.microej.com/modules/com/microej/pack/microai/microai-testsuite/)

Set the MicroAI Suite module version in the [build.gradle.kts](build.gradle.kts) to match the pack version of the tested VEE Port.

Please refer to [VEE Port Qualification Test Suite Versioning](https://docs.microej.com/en/latest/VEEPortingGuide/veePortQualification.html#test-suite-versioning)
to determine the MicroAI Test Suite module version.
